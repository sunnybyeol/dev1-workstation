# 화면 캡처와 증거

- `menu.png`: 1~6번 최신 메뉴와 실행 경로
- `play.png`: 문제 풀이 화면
- `add-quiz.png`: 퀴즈 추가 결과
- `quiz-list.png`: 저장된 퀴즈 목록
- `score.png`: 최고 점수와 최근 점수
- `quiz-del.png`: 퀴즈 삭제 후 목록 확인
- `restart-persistence.png`: 종료 후 다시 실행해 상태가 유지된 결과
- `quiz-error.png`: 메뉴 범위를 벗어난 숫자 입력과 재입력 안내
- `clone.png`, `clonelist.png`, `pull.png`: 실제 clone 및 pull 실습
- `branchlist.png`: 이전 Git 상태의 브랜치 화면입니다. 최신 병합 결과는 `logs/git-evidence.txt`를 기준으로 확인하세요.
- `2version.png`: Python 버전 확인
- `1connect.png`: GitHub 연결 정보가 포함될 수 있어 README에 미리보기로 노출하지 않습니다.

현재 실행의 메뉴·재실행 출력과 입력 예외 사례는 `logs/`에 텍스트로도 보관합니다. 텍스트 로그는 해당 명령을 실제 실행해 얻은 결과입니다.
