# 제출용 화면 캡처 체크리스트

실제 프로그램을 실행하고 터미널에서 캡처하세요. 예시 화면이나 임의 이미지를 성공 증거로 사용하지 않습니다. 캡처 파일은 이 폴더에 PNG로 저장합니다.

- `menu.png`: 시작 메뉴와 1~5번 선택지
[docs/srceenshots/menu.png](menu.png)
- `play.png`: 질문, 선택지, 정답 결과, 최종 점수
[docs/screenshots/play.png](/play.png), [docs/screenshots/play.png](play1.png)
- `add-quiz.png`: 문제 추가 성공 안내
[docs/screenshots/add-quiz.png](docs/screenshots/add-quiz.png)
- `quiz-list.png`: 추가한 문제 목록
[docs/screenshots/quiz-list.png](docs/screenshots/quiz-list.png)
- `score.png`: 최고 점수와 최근 점수
[docs/restart-persistencescreenshots/score.png](docs/screenshots/score.png)
- `restart-persistence.png`: 프로그램을 다시 켠 뒤 추가 문제와 최고 점수가 남아 있는 화면
[docs/screenshots/score.png](docs/screenshots/restart-persistence.png)

화면에 이메일, 토큰, 개인 경로 등 공개하지 않을 정보가 보이지 않는지 확인하세요.
