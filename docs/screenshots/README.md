# 화면 캡처 체크리스트

- `menu.png`: 현재 파일은 삭제 기능 추가 전 1~5 메뉴 화면입니다. 최신 1~6 메뉴 화면으로 다시 캡처해야 합니다.
- `delete-quiz.png`: 아직 없습니다. 삭제할 문제 선택, 삭제 결과, 다시 목록에서 사라진 결과를 캡처해야 합니다.
- `play.png` / `play1.png`: 질문, 선택지, 정답 결과, 최종 점수
- `add-quiz.png`: 문제 추가 성공 안내
- `quiz-list.png`: 저장된 문제 목록
- `score.png`: 최고 점수와 최근 점수
- `restart-persistence.png`: 재실행 뒤 문제와 점수가 유지된 화면
- `branchlist.png`, `clone.png`, `clonelist.png`, `pull.png`: Git 브랜치, clone, pull 실습
- `1connect.png`: 원격 설정/푸시 화면입니다. 공개 저장소에 연결할 때는 화면에 이메일 주소가 보여 개인정보가 포함될 수 있으므로 README에 직접 노출하지 않습니다.
- `2version.png`: Python 버전 확인 화면
- `3gitbranch.png`: 기존 메뉴 화면 캡처라 최신 메뉴 증거로는 사용할 수 없습니다.

캡처는 프로그램이나 Git 명령을 실제로 실행한 뒤 저장합니다. 아직 캡처하지 않은 항목은 성공 증거로 표시하지 않습니다.
